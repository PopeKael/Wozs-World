# Original CC0 assets

Place only project-created 3D models and texture files in this directory. Before inclusion, the contributor must confirm they own or control the necessary rights and agree to dedicate that original work under CC0 1.0 Universal. Keep provenance with each asset.

No original 3D models or textures are included in the 1.0.0 release. Third-party content must remain outside this directory unless its licence explicitly permits the intended inclusion and its original notices are preserved.
