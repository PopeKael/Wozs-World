# Avatar discovery sources

Primary pinned leads are listed in `PROVENANCE.md`. The following official/community sources are the starting points for continued discovery; check each live repository and its package-specific terms before acquisition:

- Ruth2 / Roth2 and the related RuthToo / RothToo / Max repositories: links in the provenance table.
- OpenSimulator user and developer documentation for inventory archives, appearance, mesh upload and region behavior: <https://opensimulator.dev/wiki/User_Documentation> and <https://opensimulator.dev/wiki/Developer_Documentation>.
- Blender official releases and add-on documentation: <https://www.blender.org/download/releases/>. Blender 4.5 LTS was the locally observed version; the current release must be rechecked when testing.
- Aurora Viewer source and releases: <https://github.com/Aurora-Viewer/Aurora-Viewer>.

Search scope for future catalogue updates: Ruth/Roth families, Max/Maxine/Maxwell, independent OpenSim bodies, public IAR archives, rigged Collada/DAE, Blender development kits, complete creator packages, and separately licensed heads, skins, eyes, hair, clothing, animations and AO systems. Do not treat inventory from a grid where an item is merely wearable as a downloadable source.
